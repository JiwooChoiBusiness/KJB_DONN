# 2026 금융 AI Challenge 기능 명세서 (팀 KJB)

팀명: KJB
구성원 성명: 최지우(팀장), 금민권(팀원)

## 1. MVP 구현 범위

- 계정: 회원가입과 로그인 없이 합성 페르소나 8명(사회초년생, 자영업자, 은퇴 전환기 등) 중 하나를 선택하거나 부채, 소득, 지출, 자산, 목표를 직접 입력. 브라우저별 세션 격리
- 홈: 인사이트 카드 3장(행동 카드, 부채 요약, 목표 진행률 또는 소비 카드), 데이터 파생 질문 칩, "이 분석은 왜 나왔나요?" 설명, 행동 카드의 "AI 설명 보기"
- 내 부채: 대출별 상환표(거치, 만기일시, 리볼빙 포함), 시나리오 3종(기준, 유리, 불리) 60개월 현금흐름과 목표 지출 반영, 자산과 연금 입력
- 공시 비교: 조건 확인(추정 항목 표시) → 익명 라벨 상위 10개(금리, 월 납입, 총이자, 현재 대비) → AI 설명(왜 이 순서인가요, 항목별 이유) → 결정 기록 저장과 재현, 이전 결과 대비 변화 표시
- 대화: 스트리밍 생각 과정, 답변 경로(직접, 내부, 외부), 리소스 패널, 후속 질의 조건 기억, 계산형 질의(추가 상환, 일시 상환, 대환, 은퇴 시점), 제도 안내 답변(요약, 핵심, 출처), 외부 검색(출처 표시, 불가 시 공식 링크), 위기 응답, 거래내역 파일 첨부 분석, 페르소나별 대화 기록
- 소비 패턴: 합성 거래내역 또는 CSV, XLSX 업로드(브라우저 파싱, 원본 미저장), 카테고리, 정기 결제, 급증, 생애 이벤트 신호, 절감액을 상환 단축으로 연결
- 생애 흐름: 생애 단계 판정, 재무비율 5개(단계별 기준값), 노후 시뮬레이션 3종, 순자산 곡선, 소득공백 지도, 목표 편집
- 제도 안내: 15편 문서 패널(출처, 확인일)과 채팅 연결
- 안전과 운영: 금칙어, 권유 표현, 숫자 검증, 안전 모드 카드, 위기 감지, 개인정보 마스킹, 호출 횟수 제한, 배포 운영, 자동 검증 러너
- PoC에서 구현하지 않은 것: 오픈뱅킹과 마이데이터 연동, 실명 상품 연결과 신청, 알림, 회원가입

## 3. 사용자 이용 흐름

1. 배포 URL(https://kjb-donn.onrender.com)에 접속한다. 첫 접속은 절전 해제로 30초에서 1분 걸릴 수 있다. 첫 화면에서 면책과 AI 고지, 예시 카드, 질문 칩을 본다
2. 왼쪽 사이드바 "계정 선택(PoC)"에서 페르소나를 고른다(예: P1 김서연). 홈에 행동 카드, 부채 요약, 진행률 카드가 나타난다. 카드의 "이 분석은 왜 나왔나요?"와 "AI 설명 보기"를 눌러 근거를 확인한다
3. 입력창에 질문을 보낸다(예: "신용대출 2천만원 36개월 비교해줘"). 대화 화면으로 전환되고 생각 과정 카드가 실시간으로 뜬 뒤 답변과 조건 카드가 나온다
4. 답변의 "조건 확인하고 비교하기"를 누르면 공시 비교 1단계에 조건이 채워진다. 추정 항목을 확인하고 실행하면 익명 라벨 순위 10개와 "왜 이 순서인가요?" AI 설명, 항목별 이유가 나온다
5. 대화로 돌아가 "금리 6.5% 이하만"이라고 보내면 직전 조건에 금리 상한만 더해 다시 준비되고, 실행하면 이전 결과와의 차이가 상단에 표시된다
6. "매달 30만 원 더 갚으면?"처럼 계산형 질문을 보내면 전후 수치와 계산 근거가 답변으로 온다. "금리인하요구권 요건이 뭐야"는 제도 안내 형식으로, "요즘 기준금리 얼마야?"는 외부 검색 경로로 답한다
7. 입력창 "+"로 거래내역 파일(CSV, XLSX)을 첨부하면 소비 패턴 요약과 절감액의 상환 효과가 답변으로 온다. 소비 패턴 화면에서 세부 결과를 본다
8. 사이드바의 내 부채, 생애 흐름, 결정 기록 화면에서 상환표와 시나리오, 재무비율과 노후 시뮬레이션, 저장된 비교 결정의 재현을 확인한다. 최근 대화는 페르소나별로 사이드바에 남는다

## 4. AI 및 데이터 처리 방식

AI가 수행하는 역할
- 의도와 조건 추출: 개인정보를 마스킹한 질문에서 의도(비교, 상환표, 시나리오, 행동, 제도, 소비, 노후, 계산형, 인사)와 조건(카테고리, 금액, 기간, 금리 상한, 제외 회사)을 JSON 스키마로 추출. 질문에 없는 숫자는 코드가 폐기
- 설명 문장 생성: 계산 결과의 범주형 사실과 자리표만 입력받아 문장을 쓰고 코드가 숫자를 채움(공시 비교 요약과 이유, 행동 카드 설명, 계산형 질의 결론, 후속 질의 안내)
- 제도 문서 요약: 참조 문단만 입력해 요약과 핵심을 작성. 문단에 없는 숫자가 나오면 규칙 렌더링으로 대체
- 직접 답변과 외부 검색: 인사와 도움말은 짧게 답하고, 내부 자료에 없는 시점성 질문은 검색 그라운딩으로 답하며 출처를 표시
- AI가 하지 않는 것: 계산, 순위 결정, 상품 선택, 위기 응답, 안전 모드 카드

사용 데이터와 입력·출력
- 공시 데이터: 금융감독원 금융상품한눈에(978건), 공공데이터포털 주택금융공사와 서민금융진흥원(936건). 스냅샷 단위로 적재하고 결정 기록에 스냅샷 ID를 남김
- 규제 파라미터와 생애 단계 기준값: 시행일, 출처, 확인 여부를 함께 관리하고 미확인 값은 "(확인 필요)" 표시
- 제도 안내 문서 15편: 출처와 확인일 기재
- 이용자 입력: 부채, 소득, 지출, 자산, 목표(직접 입력 또는 합성 페르소나), 대화 메시지, 거래내역 파일
- 입력 → 출력 요약: 질문 → 의도와 조건 JSON / 부채와 조건 → 상환표, 시나리오, 행동 카드, 비교 순위(계산 엔진) / 범주형 사실과 자리표 → 설명 문장(AI) → 숫자 채움과 검증(코드) / 거래내역 → 카테고리 요약, 정기 결제, 급증, 절감 효과(계산 엔진)

개인정보와 민감정보 처리
- 실제 개인 데이터는 사용하지 않는다. 페르소나 8명은 합성 데이터이며 직접 입력 값도 브라우저별 세션에만 저장된다
- 외부 AI로 보내는 것은 개인정보를 마스킹한 질문(전화번호, 주민등록번호, 계좌번호, 이메일 치환)과 숫자가 없는 범주형 사실뿐이다. 잔액, 소득, 금리 같은 개인신용정보 파생 수치는 전송하지 않는다
- 거래내역 파일은 브라우저에서 파싱하고 서버는 요약과 특징만 저장한다. 원본 거래와 가맹점명은 저장하지 않는다
- 외부 검색 질의에서는 숫자 토큰을 제거한 뒤 보내며, 숫자가 남으면 검색을 포기하고 공식 링크로 대체한다
- 위기 신호가 있는 메시지(자해, 연체 고통)는 외부 AI로 보내지 않고 규칙으로 감지해 공적 상담 창구를 안내한다

## 5. MVP 검증 방법

접속과 계정
- 주소: https://kjb-donn.onrender.com (별도 계정 없음). 첫 접속 시 절전 해제로 30초에서 1분 걸리면 새로고침
- 사이드바 "계정 선택(PoC)"에서 페르소나를 고르면 바로 사용할 수 있다. 심사에는 P1 김서연(사회초년생), P2 박준호(주택담보대출), P5 정수민(연체 신호)을 권한다

확인 절차와 샘플 입력, 예상 결과
1. P1 선택 → 홈: 행동 카드 "비상금부터 채우세요"(이번 달 남는 돈과 비상금 부족액 표시), 부채 요약 카드, 진행률 카드. "AI 설명 보기"를 누르면 확인된 수치, 왜 중요한지, 지금 할 일, 주의점 순서의 4~5문장 설명과 "이렇게 해보세요" 단계 목록이 붙는다(AI 응답 배지). AI 한도 소진이나 검증 실패 시 준비된 문장과 규칙 기반 배지
2. 입력창에 "신용대출 2천만원 36개월 비교해줘" → 대화 화면 전환, 생각 과정 5단계 표시, 조건 카드(신용대출, 20,000,000원, 36개월). "조건 확인하고 비교하기" → 실행 → 전체 후보 중 상위 10개(예: 1순위 A은행 신용대출 4.48%, 월 납입 594,760원, 총이자 1,411,350원, 2026년 8월 공시 기준). "왜 이 순서인가요?"에 정렬 기준, 1순위가 앞선 이유, 현재 대출 대비 차이, 심사 때 확인할 점을 담은 4~6문장 요약과 상위 3개 항목별 2문장 이유
3. 대화로 돌아가 "금리 6.5% 이하만" → 조건 카드에 금리 상한 6.5%가 추가됨. 실행하면 결과 상단에 이전 결과 대비 변화(바뀐 조건, 후보 수, 1순위, 총이자 차이)
4. "카드론이랑 마이너스통장 중에 뭐부터 갚아야 해? 이유도 자세히 알려줘" → 최우선 행동 카드를 근거로 한 4~5문장 답변(대상 대출, 이유, 지금 할 일, 주의점)과 단계 목록. 리소스 패널에 내 대출과 계산 결과가 잡힘
5. "매달 30만 원 더 갚으면 얼마나 빨리 끝나? 계산 근거도 보여줘" → 결론 2문장, 계산 근거 3~4개(대상 대출, 단축 개월, 절감 이자, 새 완료 시점), 가정 1줄, 칩 "시나리오로 확인하기". "신용대출을 금리 4%로 갈아타면?"은 대환 효과(월 납입 차이, 총이자 차이, 수수료 회수 기간)로 답한다
6. "금리인하요구권 요건과 절차를 자세히 알려줘" → 제도 안내 카드(요약 2문장, 핵심 최대 5개, "이렇게 활용하세요" 한 줄, 출처와 확인일, 자세히 보기). "요즘 기준금리 얼마야?" → 외부 검색 요약(확인 필요) 배지 또는 공식 안내 링크
7. P5 선택 → 홈: 안전 모드 카드가 첫 번째. 입력창에 "연체돼서 독촉 전화가 계속 와요. 너무 힘들어요" → 신용회복위원회 1600-5500, 서민금융콜센터 1397 등 공적 상담 안내(AI 미사용, 규칙 기반 응답 배지)
8. 입력창 "+"로 거래내역 파일 첨부(소비 패턴 화면의 "합성 데이터로 분석" 또는 P3 합성 CSV 다운로드 후 업로드) → 월평균 지출과 소득 대비 비율, 핵심 항목 3~5개, "이렇게 연결돼요"(절감액 → 단축 개월과 절감 이자)가 답변으로 표시
9. 결정 기록 화면 → 방금 비교의 "재현"을 누르면 해시 일치 표시. 기술 정보(결정 ID, 결과 해시, 스냅샷 ID)는 접힌 항목에서 확인

실행 환경과 브라우저
- Chrome, Edge 최신 버전. 데스크톱 1280px 권장, 모바일 375px 지원(사이드바 접힘, 입력창 하단 고정)
- 파일 첨부는 CSV 또는 XLSX 10,000행 이하. 날짜와 금액 열이 있어야 하며 자동 매핑 실패 시 소비 패턴 화면에서 열을 지정

MVP 단계의 제한사항
- 무료 호스팅이라 15분 무접속 시 절전되고 첫 접속이 느리다. 서버 재시작 시 세션 데이터(대화, 결정 기록)는 초기화되고 공시 데이터는 시드에서 다시 적재된다
- 생성형 AI는 무료 티어라 일일 한도에 도달하면 규칙 기반 모드로 자동 전환된다(응답 배지로 구분). 이때 설명 문장은 준비된 짧은 문장으로 대체되며 화면과 계산은 동일하게 동작한다
- 공시 데이터는 2026년 8월 스냅샷이며 실제 승인 금리와 한도는 금융회사 심사에 따라 다르다. 상품 실명은 표시하지 않는다(정보 제공 모드)
- 외부 검색은 한도나 응답 불가 시 공식 기관 링크 모음으로 대체된다
- 페르소나는 합성 데이터이며, 오픈뱅킹과 마이데이터 연동과 실명 상품 신청은 PoC에서는 구현하지 않았다
