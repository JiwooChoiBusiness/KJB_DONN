| 항목 | 내용 |
|---|---|
| 작성일 | 2026-09-06 |
| 목적 | 내부 시연·페르소나 테스트·투자/파트너 설명용 **동작하는 데모**. 실사용자 데이터 없음 |

## 1. 데모에서 보여줄 것 (6개 장면)

| # | 장면 | 사용자 눈에 보이는 것 | 뒤에서 도는 것 |
|---|---|---|---|
| 1 | 첫 화면(C안 하이브리드) | 인사이트 카드 1~3장 + 데이터 파생 칩 3~5개 + 입력창, 면책·AI 고지 상시 | 배치 계산 결과 렌더. **LLM 호출 0회** |
| 2 | 부채 입력 → 행동 카드 | 최소 5개 값 입력 → "이번 달 할 단 하나의 행동" 카드(수치·근거·가정) | 결정론 코어: 상환표·총이자·3 시나리오·룰 R0~R6 |
| 3 | 조건 확인 → M0 공시 비교 | 추정 조건 확인·수정 → "내 조건으로 본 공시 비교"(익명 표기, 단일 기준 정렬, 금감원 공시 링크) | 금감원·공공데이터 스냅샷 필터·정렬·계산기, 결정 기록(decision_id·result_hash) |
| 4 | 후속 질의 재실행 | "금리 4% 이하만", "기간 5년으로" → 바뀐 항목 diff 설명 | Gemini (a) 델타 추출(JSON 스키마) → 시나리오 계산기 재계산(ms) → (f) 슬롯 필링 설명 |
| 5 | 소비패턴 인사이트 | 거래내역 CSV/XLSX 업로드(또는 합성 데이터 선택) → 앱 진입 시 자동 집계 카드 | **브라우저 내 파싱·집계**(서버 미전송), 카테고리 룰 분류, 구독·이상치 탐지 |
| 6 | 페르소나 러너 | 페르소나 8명 × 골든 질문 실행 결과 리포트 | 시나리오 재현(result_hash 동일), 선택적 LLM judge |

## 2. In / Out

**In (PoC)**
- 결정론 코어: 원리금균등·원금균등·만기일시·거치, 총이자, 조기상환·중도상환수수료, 대환 시나리오, 기본/불리/유리 3 시나리오, 단일 기준 정렬, 룰 R0~R6, 시나리오 계산기
- 규칙 레지스트리(`policy_params`: 시행일·출처·확인일·'(확인 필요)' 플래그)
- 상품 스냅샷 적재기: 금감원 금융상품한눈에(정기예금·적금·주담대·전세·개인신용대출) + 공공데이터포털(서민금융진흥원 대출상품한눈에, 금융위 서민금융 기본정보, 주금공 디딤돌 금리)
- 합성 데이터: 페르소나 8명 프로필 + 합성 거래내역 생성기
- 첫 화면 C안, 부채 입력 폼, 조건 확인 카드, M0 결과 블록, 후속 질의 UI(조건 바텀시트 + diff)
- Gemini 어댑터: (a) 추출, (f) 설명, 자유 질의 오케스트레이터(도구 최소 6종), 오프라인 judge
- 제도 안내 KB: 법령·제도 설명 문서(kb/*.md, 출처·확인일 기재) + 키워드 검색 모듈. 상품·금융회사 실명 없음. 채팅의 faq 의도에 연결 (2026-09-06 PMO 결정)
- 가드레일 최소본: 상품명·회사명·시장금리 검출 필터, PII 필터, 프롬프트 인젝션 기본 방어, 템플릿 폴백
- 결정 기록·재현 테스트, 골든 벡터 테스트, 면책·AI 고지 100% 노출
- README(PMO 혼자 실행 가능), 데모 시나리오 스크립트

**Out (PoC 제외)**
- **오픈뱅킹** (PMO 결정 2026-09-06 — MVP 단계로 이월, 이용기관 신청 시점도 PoC 이후)
- 마이데이터, 서류 OCR, CB 제휴
- 실명 상품·은행 바로가기·제휴 링크(M1 모드), 예·적금 순위(D5)
- 회원가입·인증·동의 실동작(데모 계정 1개, 동의 화면은 목업), 알림·푸시, 결제·유료화
- 실사용자 데이터, 클라우드 배포(로컬 실행; 필요 시 단일 컨테이너)
- Anthropic 등 다른 공급자 어댑터(인터페이스만 두고 미구현)
- 몬테카를로·ML 예측, 임베딩 기반 분류, 네이티브 앱

| 사용자 데이터 | 부채·소득·고정지출·거래내역 | 합성 생성기 + 수기 입력 폼 + 브라우저 내 CSV/XLSX 파싱 | 서버에는 집계 피처만 저장(D3 원칙을 PoC에서도 유지) |

## 4. LLM(Gemini) 사용 위치

| 위치 | 입력 등급 | 출력 | 실패 시 |
|---|---|---|---|
| (a) 발화→변수·델타 추출 | G2 발화(PII 필터 후) | JSON 스키마 강제, 온도 0 | 규칙 기반 파서 폴백 + 조건 확인 카드에서 사용자 수정 |
| (f) 슬롯 필링 설명 | 범주형 코드·플레이스홀더만(G3 수치 금지) | 문장 템플릿, 스트리밍 | 고정 템플릿 폴백 |
| 자유 질의 오케스트레이터 | G2 발화 + 도구 결과 요약 | 도구 호출 → 답변('시뮬레이션 결과 + 고려 요소'까지) | 도구 결과 직접 렌더 |
| judge(오프라인) | 합성 데이터만 | 루브릭 점수 JSON | 사람 검수 |

모델 ID·가격·속도 제한·데이터 정책은 키 수령 후 확인해 `config/llm.yaml`에 기록 **(확인 필요)**.

## 5. 기술 스택 제안 (PMO 확인 후 확정, 이의 없으면 이대로 진행)

| 층 | 선택 | 이유 |
|---|---|---|
| 백엔드 | Python 3.12 + FastAPI, pydantic, SQLite(스냅샷·결정 기록·피처), pytest | PMO PC(Windows)에서 한 줄 실행, 금융 계산 테스트 용이 |
| 프론트 | 단일 페이지 HTML + 경량 JS(빌드 도구 없음), 파일 파싱은 브라우저 JS(SheetJS) | 데모 속도·유지 부담 최소. 필요 시 React로 이전 가능 |
| LLM 어댑터 | `app/llm/provider.py` 인터페이스 + `gemini.py` | 공급자 교체 가능 |
| 실행 | `uvicorn` 로컬, `.env`에 `GEMINI_API_KEY` | 키는 PMO가 직접 `.env`에 기입(채팅에 붙여넣지 않음) |
| 대안 | Node/Next.js 풀스택 | PMO 선호 시 변경 |

## 6. 실행 순서 (마일스톤)

| 단계 | 산출물 | 시연 가능 상태 |
|---|---|---|
| P1 | 리포 스캐폴드, 결정론 코어, 골든 벡터 테스트, 규칙 레지스트리 시드 | 계산기 CLI |
| P2 | 상품 스냅샷 적재기(금감원·공공데이터), 합성 데이터 생성기(페르소나 8명) | 데이터 브라우저 |
| P3 | 첫 화면 C안 + 부채 입력 + 행동 카드 + 조건 확인 + M0 공시 비교 | **LLM 없이 장면 1~3 시연** |
| P4 | Gemini 어댑터: 추출·설명·후속 질의 재실행, 가드레일 최소본, **제도 안내 KB**(금리인하요구권·채무조정·DSR 등 제도 문서 10여 개, 임베딩 없는 키워드 검색, 상품명 없음) | 장면 4 + 제도 질문 응답 |
| P5 | 브라우저 내 거래내역 파싱·집계·소비 카드 | 장면 5 |
| P6 | 페르소나 러너 + 리포트 + 데모 스크립트 + README | 장면 6, 전체 시연 |

## 8. PoC 완료 기준

- 페르소나 8명 시나리오가 끝까지 재현되고 `result_hash`가 실행마다 동일
- 첫 화면 로드 LLM 호출 0회, 후속 질의 재계산 300ms 이내(계산), 설명 생성 4초 이내
- 면책·AI 고지 노출률 100%, 상품명·회사명 검출 필터 통과 0건
- README만으로 PMO가 혼자 실행·시연 가능
